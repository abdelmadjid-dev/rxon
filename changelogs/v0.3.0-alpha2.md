# RxOn v0.3.0-alpha2 Release Notes

## Universal Async Composition & Semantic Side-Effects
v0.3.0-alpha2 completes the lazy orchestration engine by providing non-blocking asynchronous task integration and pipeline composition across all supported schedulers.

### Core Changes
* **Sub-Pipeline Composition**: Added `thenChain()` and `then()` to allow merging or dynamic chaining of pipelines without execution nesting.
* **Async Integration (All Schedulers)**: Added `thenReadSingle()`, `thenWriteSingle()`, `thenIoSingle()`, `thenComputeSingle()`, and `thenMainSingle()` to integrate `Single`-returning tasks without blocking the underlying thread pools.
* **Semantic Side-Effect Operators**: Introduced `peekRead()`, `peekWrite()`, `peekIo()`, `peekCompute()`, and `peekMain()` for cleaner side-effect definitions that don't alter the pipeline value or context.

Refer to the [Migration Guide](../migrations/MIGRATION_0.3.0-alpha_TO_0.3.0-alpha2.md) for upgrade instructions.
