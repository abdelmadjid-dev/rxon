# RxOn v0.3.0-alpha10 Release Notes - "Emitter Diagnostics & Release Automation"

This release enhances error mapping diagnostics for callback emitter functions and introduces automated GitHub Release notes generation and publishing CI/CD automation.

## Key Features & Enhancements

### 1. Emitter Diagnostics & Exception Sanitization
Wrapped underlying `SingleEmitter` and `CompletableEmitter` instances in delegating proxy emitters within `Work.singleEmitter(...)` and `Work.completableEmitter(...)`:
- All errors emitted via `emitter.onError(t)`, `emitter.tryOnError(t)`, or uncaught within the emitter block are automatically processed through `RxOnConfig.mapError(t)`.
- Strips internal `RxJavaAssemblyException` noise cleanly from async callback pipelines before propagating downstream.

### 2. CI/CD GitHub Release Automation
Updated `.github/workflows/publish.yml` with `softprops/action-gh-release@v2`:
- Automatically creates an official GitHub Release upon tag publication (`v*`).
- Generates structured changelogs (`generate_release_notes: true`) from commit history and pull requests.
- Triggers GitHub release email notifications to repository watchers.
