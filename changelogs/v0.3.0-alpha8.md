# RxOn v0.3.0-alpha8 Release Notes - "Release Integrity & Developer Experience"

This release introduces automated guardrails to ensure release integrity and a streamlined developer experience for contributors.

## Infrastructure Improvements

### 1. Automated Release Guardrails
Implemented a multi-layered verification system to prevent releases with missing documentation or version mismatches:
- **Pre-commit Checks**: Automatically verifies that changelogs, migration guides, and documentation are updated before allowing a commit.
- **Pre-push Guard**: Detects version tag pushes (`v*`) and performs a final consistency check between the tag and the library version.
- **Standalone Verification**: Moved verification logic to a lightweight shell script to avoid Gradle overhead and ensure fast, isolated checks.

### 2. Zero-Touch Developer Setup
Simplified the project onboarding process:
- **Auto-Installing Git Hooks**: Git hooks are now automatically installed and updated during Gradle initialization (IDE sync or any build). 
- **Conventional Commits**: Enforced the Conventional Commits standard for a cleaner, more searchable project history.

### 3. Refined Configuration API (Carry-over)
Ensured the non-exclusive configuration DSL and the improved error mapping pipeline order from alpha7 are fully documented and verified.

## Bug Fixes
- Fixed a Gradle configuration issue where release checks would fail in environments missing specific Android SDK components (e.g., CI environments focused on Java-only library builds).
